# Planora — Personal Finance & Expense Tracker

Planora is a modern, intuitive, and feature-rich personal finance dashboard designed to help users track expenses, manage budgets, organize transaction categories, and analyze spending patterns. It provides a visual and interactive interface to help you take control of your financial health.

## 🚀 Key Features

- **Interactive Financial Dashboard**: 
  - Real-time visualization of monthly expenses using Recharts (Pie Chart category breakdown & daily cumulative Line Chart).
  - Monthly budget limit progress bar and comparisons to previous month's spending.
  - Quick view of recent transactions.
- **Detailed Transactions Manager**: Log, edit, and view individual expenses, including items, dates, and costs.
- **Dynamic Category Management**: Create and configure custom spending categories (e.g., Groceries, Utilities, Dining, Entertainment).
- **Receipts Management**: Upload and process receipt data.
- **Authentication Support**: Built-in authentication (login/signup) matching with backend API tokens.

## 🛠️ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/router/v1/docs/start/overview) (powered by React 19 & Vite 8)
- **Routing**: [TanStack Router](https://tanstack.com/router/v1/docs/guide/introduction) (type-safe routing)
- **State & Data Fetching**: [TanStack Query](https://tanstack.com/query/latest) (React Query)
- **Styling**: [TailwindCSS v4](https://tailwindcss.com/) & [Radix UI](https://www.radix-ui.com/) components
- **Charting**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
